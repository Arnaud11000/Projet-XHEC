## Projects

### 1. Forest Cover Type Classification

**Status:** In progress

A machine learning project exploring the prediction of forest cover types using cartographic and environmental data.

Beyond predictive accuracy, the project focuses on understanding how model complexity, feature characteristics, and validation strategies influence generalization to unseen observations.

**Main research questions:**
- How does model complexity affect overfitting and out-of-sample performance?
- Which features contribute to predictive accuracy?
- How robust are models to changes in data distributions?

**Methods:** Exploratory Data Analysis, statistical learning, classification algorithms, cross-validation, and robustness experiments.
